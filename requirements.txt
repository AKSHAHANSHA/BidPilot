# Runtime dependencies installed by Vercel's Python runtime for api/index.py.
#
# Vercel reads this file from the repository root and does NOT read backend/pyproject.toml, so
# the list is maintained here by hand. It mirrors `[project].dependencies` in
# backend/pyproject.toml with three deliberate differences, each justified below. Keep the two
# in sync when a runtime dependency is added.
#
# Omitted on purpose:
#   uvicorn[standard]  Vercel supplies the ASGI server; nothing here ever runs uvicorn. Its
#                      extras (uvloop, httptools, watchfiles) are pure weight in a function
#                      bundle that has a hard 250 MB unzipped limit on the Hobby plan.
#   alembic            Migrations are run from a developer machine against the database, not
#                      from inside a request (deploy/VERCEL.md §6). Nothing in `app/` imports it.
#
# Kept even though this deployment never uses it:
#   dramatiq[redis]    JOB_EXECUTION=inline never enqueues, but DramatiqJobQueue imports it
#                      lazily. A misconfigured JOB_EXECUTION should fail as a clear error from
#                      our own code path rather than as a missing module.
#
# Not optional despite Redis being unused: app/core/redis_client.py imports `redis.asyncio` at
# module scope and app/main.py imports that module, so the package must be installed. No
# connection is opened at import time — only the rate limiter and /health/ready dial out, and
# the rate limiter fails open.
